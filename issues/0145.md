# 0145 — TLSTransportTests.opensslSeesCloseNotifyOnlyOnClose is flaky under load

| | |
|---|---|
| **Status** | open |

| **Platform** | macOS |

## Description

The test failed twice in parallel runs under load (once on 2026-11-12 in a full suite, once on 2026-11-13 in a filtered parallel run, "child exited early with 0"), and passed every time it ran alone. The `openssl s_client` child apparently exits before the test's expected close_notify point when the machine is busy.

## Acceptance criteria

- Find why the child exits early (timing assumption, stdin EOF, buffering) and make the test deterministic without making it slower than a few seconds.
- 20 repeated runs under parallel load pass.
